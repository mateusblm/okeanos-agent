# Credits

Step 5 (the ladder and the proof of each new check) and step 6 (**Keep `docs/agents/regras.md`**) are adapted from [Lauren Tan](https://github.com/poteto)'s [`correct`](https://github.com/cursor/plugins/tree/main/pstack/skills/correct) (MIT, Copyright (c) 2026 Lauren Tan), with the "pick the strongest mechanism" idea from the same author's `principle-encode-lessons-in-structure`: fix at the highest level that works (architecture, types, a check whose error names the fix, a test, docs last), prove each new check fails on a real past mistake, and keep a table pairing each rule with what enforces it, treating an unenforced rule that is broken again as a repeat. The adaptation draws the past mistakes from the Okeanos metrics log as well as git, adds `checks.json` as a check rung, requires saying so when no past mistake exists to prove a check, and keeps the table in `docs/agents/regras.md` instead of the agent instruction file, so it doesn't weigh on every turn.
